# 6. Project Testing

## Overview

This phase focuses on testing the EduGenie - Google Gemini Powered Learning Assistant.

## Testing Objectives

- Verify that the main application works correctly.
- Test the Question and Answer feature.
- Test the simplified explanation feature.
- Test the quiz generation feature.
- Test the text summarization feature.
- Test the learning path recommendation feature.
- Identify and handle errors during application use.

## Testing Approach

EduGenie is tested using functional testing and user input validation. Each major feature is checked with suitable inputs to verify that the expected output is produced.

## Main Features Tested

1. Question and Answer
2. Simplified Explanation
3. Quiz Generation
4. Text Summarization
5. Learning Path Recommendation

## Expected Outcome

The application should accept user input, process the request through the appropriate module and Gemini AI service, and display a meaningful result to the user.

## Conclusion

Testing helps verify the functionality, reliability and usability of the EduGenie application before demonstration and deployment.
